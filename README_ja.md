# elab-agent

[elabFTW](https://www.elabftw.net/) のデスクトップコンパニオン — 実験データのアップロード、エントリ管理、スマートフォンからのリアルタイム実験記録に対応。elabFTW のウェブインターフェースに触らずに使えます。

## 何ができるのか

**elab-agent** は実験ファイルと elabFTW 電子実験ノートの間を仲介します。Word ドキュメント、PDF、画像のバッチをドロップすると、アプリケーションが内容を解析し、実験 ID を検出し、プレビューを表示してから、正しい順序で適切な elabFTW エントリにアップロードします。

2 つのエディションがあります：

| エディション | 含まれるもの |
|---------|-------------|
| **PDF Only** | PDF アップロードのみ — 調整なしで一括アップロードする場合に便利 |
| **Full Version** | Word (.docx)、PDF、画像・ビデオアップロード、ベンチコンパニオン |

## ダウンロード

[**Releases**](../../releases) ページから、あなたのプラットフォーム用ファイルをダウンロードしてください：

| プラットフォーム | ファイル | 備考 |

| Windows | `elab-agent-x.y.z-x64-setup.exe` | ウィザード付きインストーラー |

## インストール

### Windows

1. `*-setup.exe` をダウンロードしてダブルクリック。
2. インストーラーが表示され、**Install** をクリック、待機後 **Finish** をクリック。
3. スタートメニューまたはデスクトップから **elab-agent** を見つけます。

### macOS

`.pkg` インストーラーの場合：

1. お使いのチップに合わせて `.pkg` をダウンロード（arm64 = Apple Silicon、x64 = Intel）。
2. ダブルクリック → 3 ステップのインストーラーをクリック。
3. アプリケーションフォルダから **elab-agent** を開きます。

> macOS が「未確認の開発元」と表示する場合：  
> ファイルを右クリック → **開く** → ダイアログで **開く**。
>
> macOS が「Apple は "`elab-agent-*.pkg`" を検証できません」と表示する場合：  
> **完了** をクリック → **システム設定** を開く → **プライバシーとセキュリティ** に移動 → **セキュリティ** セクションまで下にスクロール → **とにかく開く** をクリック（"`elab-agent-*.pkg` はお使いの Mac を保護するためにブロックされました"）

`.dmg` インストーラーの場合：

1. イメージをマウント
2. elab-agent をアプリケーションフォルダにドラッグして配置
3. スタートメニューまたはデスクトップから **elab-agent** を見つけます。

> macOS が「このアプリケーションは損傷しているため開くことができません」と表示する場合：
>
> 下記を実行してください：`xattr -cr /Applications/elab-agent`

### Linux (AppImage)

```bash
chmod +x elab-agent-*.AppImage
./elab-agent-*.AppImage
```

### Linux (.deb)

```bash
sudo dpkg -i elab-agent-*.deb
# その後、アプリケーションメニューから起動するか、以下を実行：
elab-agent
```

## 初回起動 — モード選択

elab-agent を初めて開くと、ランチャーが表示されます：

- **PDF Only** — コミュニティモードでアプリを起動（PDF アップロードのみ）。複数の研究者で共有するラボに向きます。
- **Full Version** — すべての機能で起動。PIN 保護で認可されたユーザーのみアクセス可能。

![ランチャースクリーン](screenshots/launcher.png)

## セットアップウィザード

モードを選択すると初回のみ、セットアップウィザードが 4 ステップで案内します：

1. **Server** — elabFTW サーバー URL を入力し、接続可能か確認。
2. **Template & resource** — 使用する実験テンプレートとリソースカテゴリを選択。
3. **ID pattern** — ラボの実験 ID フォーマット（例：`TFA x_yyy` → `TFA 1_001` にマッチ）を定義。
4. **Markers** *(オプション)* — PDF ノートブック内のページをグループ化するための開始・終了キーワードを設定。

設定はローカルに保存されます。いつでも **Settings → Reconfigure** から再設定できます。

![セットアップウィザード](screenshots/setup-wizard.png)

## ファイルのアップロード

### Word (.docx) — Full Version のみ

Word ドキュメントをアップロードゾーンにドロップ。elab-agent はセクション区切りでページを分割し、各ページから実験 ID を検出し、ChemDraw スキーマティックスを自動抽出します。

ページごとのプレビューが表示され、以下の情報が含まれます：
- 検出された ID（間違っていれば編集可能）
- スキップトグル（アップロードしたくないページを除外）
- ID が elabFTW に既に存在する場合は重複警告
- Anthropic API キーが設定されている場合、AI タグ候補

**Upload all** をクリック、または キーボードショートカット `Ctrl+Enter` ですべてをアップロード。

![Word アップロード確認](screenshots/word-review.png)

### PDF

PDF をドロップ。各ページが画像としてレンダリングされ、実験 ID が検出され、ページがエントリにグループ化されます。複数ページのグループは 1 つのインライン画像に統合されます。

- **Split / Merge** — ページグループを 1 クリックで結合・分割。
- **ドラッグで並び替え** — カードをドラッグしてアップロード順序を変更。
- **カード単位のアップロード** — バッチ全体をアップロードせず、個別エントリをアップロード。

![PDF レビューパネル](screenshots/pdf-review.png)

### 画像

1 つ以上の画像（JPG、PNG、TIFF、WEBP、HEIC）をドロップ。各画像は実験エントリにマッチングされます。画像は実験本体ではなく、リソースエントリに記録されます。

### 一括アップロード

複数ファイルを一度にドロップ。ファイルキューがトップに表示され、矢印ボタンで移動するか、ドロップダウンをクリックして選択できます。各ファイルは独立して処理されます。

## キーボードショートカット

| キー | アクション |
|-----|--------|
| `j` / `k` | 次へ / 前へ |
| `s` | 現在のエントリをスキップ |
| `u` | 現在のエントリをアップロード |
| `Ctrl+Enter` | すべてをアップロード |
| `?` | このヘルプを表示 |

## ベンチコンパニオン — Full Version のみ

ベンチコンパニオンでは、実験中にスマートフォンからリアルタイムメモ、写真、ビデオを取得し、最後に一度に elabFTW にアップロードできます。

### セッション開始

1. デスクトップアプリで **Bench** に移動し、新しいセッションを開始（ID とタイトルを入力）。
2. スマートフォンのブラウザで、スクリーン上に表示される URL（例：`http://192.168.1.x:3000/bench`）にアクセス。アプリインストール不要。
3. 実験中にステップを追加します。メモと写真は 30 秒ごとに自動保存されます。

![モバイルのベンチコンパニオン](screenshots/bench-mobile.png)

### 機能

- **ストップウォッチ** — 反応時間を測定でき、スプリットとラップを追加可能（各ステップのタイミング用）。
- **写真とビデオ** — インライン取得。iOS HEIC 画像は自動変換されます。
- **オフラインモード** — ネットワークが切れた場合、オレンジ色のバナーが表示され、メモはバッファされて接続が復帰するまで待機。
- **セッション複製** — 前回のセッションステップ構造をコピーして新規セッション開始を高速化。
- **アップロード** — 実験完了後、デスクトップアプリから **Upload to elabFTW** をタップ。

## アップロード履歴

**History** タブには今回のセッション内で実行したすべての操作のログが記録されます：

- **Uploads** — elabFTW に送信されたファイルのステータス（成功 / 失敗）。
- **Created** — 手動作成ツールで作成されたエントリ。
- **Deleted** — 一括削除ツールで削除されたエントリ。
- **Bench** — アップロードされたベンチセッション。

失敗したアップロードには **↺ Retry** ボタンがあり、アップロードページに戻ってどのファイルを再度ドロップするかのヒントが表示されます。

Word または PDF レビューパネルから **Export CSV** でも可能です — 「All entries」または「Uploaded only」を選択。

## 複数サーバープロファイル

複数の elabFTW サーバーで作業する場合、トップナビゲーションバーの **Profiles** を使用：

1. サーバーに接続して通常通り API キーを入力。
2. ナビゲーションバーで **Profiles** → 名前を入力 → **Save**。
3. ワンクリックでプロファイルを切り替え — API キーの再入力不要。

API キーはブラウザのローカルストレージにのみ保存され、どのサーバーにも送信されません。

## 実験の管理

**Create / Delete** タブで以下が可能：

- **Create** — 新しい空白の実験エントリを手動作成（ベンチセッション前のセットアップに便利）。

- **Delete** — サーチバーを使用して 1 つのエントリを削除
- **Bulk delete** — 実験を検索し、チェックボックスをオンにして一括削除。

## テンプレート選択

各アップロードセッションで異なる elabFTW テンプレートを使用できます。レビューパネルヘッダーの **Template** ドロップダウンをクリックして切り替え。テンプレートの横の **👁**（目）ボタンをクリックして、選択前にプレビュー可能。

## ダークモード

ナビゲーションバー右上の **☾** ボタンをクリックしてダークモードを切り替え。設定は保存されます。

## 高度な機能 — AI タグ候補

AI API キーがある場合、elab-agent は各実験エントリのタグを候補から提案できます。セットアップウィザード（ステップ 4）または **Settings** 経由でキーを入力。タグ候補はレビューパネルにインラインで表示され、受け入れまたは却下できます。

## トラブルシューティング

### 「elabFTW に接続できません」
- サーバー URL が正しいか確認（`https://` を含める）。
- API キーが有効期限切れでないか確認。
- VPN を使用している場合は接続状態を確認。

### Linux でアプリが起動しても画面が空白
- `.deb` パッケージを使用している場合、`--no-sandbox` フラグで実行を試行。
- ランディングページの **Logs** ボタンをチェックしてバックエンド エラーメッセージを確認。
