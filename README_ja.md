# elab-agent

[elabFTW](https://www.elabftw.net/) 用デスクトップ補助ツール — 実験データのアップロード、エントリの管理、スマートフォンからのライブベンチメモ記録を、elabFTW の Web インターフェースを開かずに行えます。

---

## 概要

**elab-agent** は、実験ファイルと elabFTW 電子実験ノートの間に立つ橋渡しツールです。Word 文書、PDF、画像、またはその他のファイルをドロップすると、ドキュメントを解析して実験 ID を検出し、プレビューを表示したあと、正しい elabFTW エントリに正しい順序でアップロードします。

2 つのエディションがあります。

| エディション | 機能 |
|------------|------|
| **アップロード専用** | Word、PDF、画像のアップロード — 共有インストール向け |
| **フルバージョン** | アップロード専用の全機能 ＋ 任意ファイル添付、ライブベンチ記録、実験の作成・削除 |

## インストール

### Windows

1. `*-setup.exe` をダウンロードしてダブルクリックします。
2. インストーラーが表示されたら **Install** をクリックし、完了後 **Finish** を押します。
3. スタートメニューまたはデスクトップから **elab-agent** を起動します。

### macOS

`.pkg` を使う場合:

1. チップに合った `.pkg` をダウンロードします（arm64 = Apple Silicon、x64 = Intel）。
2. ダブルクリックして 3 ステップのインストーラーを進めます。
3. Applications フォルダから **elab-agent** を開きます。

> macOS が「開発元を確認できない」と表示する場合:
> ファイルを右クリック → **開く** → ダイアログで再度 **開く**。
>
> 「Apple は "elab-agent-*.pkg" を確認できません」と表示される場合:
> **完了** をクリック → **システム設定** → **プライバシーとセキュリティ** → **セキュリティ** → **このまま開く** をクリック。

`.dmg` を使う場合:

1. イメージをマウントします。
2. elab-agent を `/Applications` フォルダにドラッグします。
3. Applications フォルダから起動します。

> 「"elab-agent" は壊れているため開けません」と表示された場合:
>
> ```bash
> xattr -cr /Applications/elab-agent.app
> ```

### Linux (AppImage)

```bash
chmod +x elab-agent-*.AppImage
./elab-agent-*.AppImage
```

### Linux (.deb)

```bash
sudo dpkg -i elab-agent-*.deb
# アプリケーションメニューから起動するか:
elab-agent
```

## 初回起動 — モード選択

elab-agent を初めて開くとランチャーが表示されます。

- **アップロード専用** — コミュニティモードで起動します（Word・PDF・画像のアップロード）。共有インストールに適しています。
- **フルバージョン** — 全機能で起動します。PIN 保護を設定して承認ユーザーのみがアクセスできるよう制限できます。

起動後、ランディングページ左上の **switch** ボタンからランチャーに戻ってモードを変更できます。

---

## セットアップウィザード

モードを選択すると、4 ステップのセットアップウィザードが起動します。

1. **サーバー** — elabFTW サーバーの URL を入力し、接続確認を行います。
2. **テンプレートとリソース** — 使用する実験テンプレートとリソースカテゴリを選択します。
3. **ID パターン** — 研究室の実験 ID フォーマットを設定します（例: `TFA x_yyy` → `TFA 1_001` に一致）。
4. **マーカー** *(省略可)* — PDF ノートのページをグループ化するための開始・終了キーワードを設定します。

設定はローカルに保存されます。**設定 → 再設定** からいつでも変更できます。

---

## リソースカテゴリ

リソースカテゴリは、リンクされたリソースエントリを作成する際に使用するテンプレートを決定します。現在のカテゴリはランディングページに表示されています。横の **change** をクリックすると、elabFTW サーバーから取得したリストから別のカテゴリを選択できます — 変更はすぐに有効になり、再設定は不要です。

## ファイルのアップロード

### Word (.docx)

Word 文書をアップロードゾーンにドロップします。セクション区切りでページに分割し、各ページの実験 ID を検出して ChemDraw スキーマを自動抽出します。

ページごとのプレビューには以下が含まれます。
- 検出された ID（誤りがあれば編集可能）
- アップロードしないページをスキップするトグル
- elabFTW に同じ ID が既に存在する場合の重複警告
- AI タグ候補（Anthropic API キーが設定されている場合）

**Upload all** または `Ctrl+Enter` で一括アップロードできます。

### PDF

PDF をドロップします。各ページが画像としてレンダリングされ、実験 ID が検出されてエントリにグループ化されます。

- **分割 / 結合** — ページグループをワンクリックで結合または分割。
- **ドラッグで並べ替え** — カードをドラッグしてアップロード順を変更。
- **個別カードアップロード** — バッチ全体を処理せずに個別エントリをアップロード。

### 画像

1 枚以上の画像（JPG・PNG・TIFF・WEBP・HEIC）をドロップします。各画像は実験エントリに紐付けられます。画像は実験本文ではなくリソースエントリに保存されます。

### 追加ファイル — フルバージョンのみ

Word または PDF のアップロード後（または未認識ファイルをドロップしたとき）に **追加ファイルをアップロード** パネルが表示されます。生データ、スペクトル、スプレッドシートなど任意のファイルを、解析やプレビューなしで実験のリソースエントリに直接添付できます。

- **既存に紐付け** — ID またはタイトルで実験を検索して、そのリソースにファイルを添付。
- **新規作成** — 新しい実験エントリを作成して同時にファイルを添付。

ファイルごとの進行バーで各アップロードを追跡します。一部失敗した場合は失敗したファイルの一覧と **↺ 失敗分を再試行** ボタンが表示されます。

### バッチアップロード

複数のファイルを一度にドロップできます。上部にファイルキューが表示され、矢印ボタンまたはドロップダウンで移動できます。各ファイルは独立して処理されます。

## キーボードショートカット

| キー | 操作 |
|------|------|
| `j` / `k` | 次 / 前のエントリ |
| `s` | 現在のエントリをスキップ |
| `u` | 現在のエントリをアップロード |
| `Ctrl+Enter` | 全エントリをアップロード |
| `?` | ヘルプの表示・非表示 |

## ベンチ記録 — フルバージョンのみ

ベンチ記録機能は、実験中にスマートフォンからライブメモ・写真・動画をキャプチャし、実験終了後に一括で elabFTW にアップロードします。

### セッションの開始

1. デスクトップアプリで **Bench** に移動し、新しいセッションを開始します（ID とタイトルを入力）。
2. スマートフォンのブラウザで画面に表示された URL（例: `http://192.168.1.x:3000/bench`）を開きます。アプリのインストールは不要です。
3. 実験を進めながらステップを追加します。メモと写真は 30 秒ごとに自動保存されます。

### 機能

- **ストップウォッチ** — 反応時間の計測、スプリット・ラップで各ステップのタイムを記録。
- **写真・動画** — インラインでキャプチャ。iOS の HEIC 画像は自動変換されます。
- **オフラインモード** — ネットワークが切断されると琥珀色のバナーが表示され、接続が回復するまでメモがバッファリングされます。
- **アップロード** — 実験終了後、デスクトップアプリから **Upload to elabFTW** をクリックします。

---

## アップロード履歴

**History** タブにはこのセッション中のアップロード記録が保存されます。

- **Uploads** — elabFTW に送信されたファイルとステータス（成功・失敗）。追加ファイルのアップロードも含まれます。
- **Created** — 手動作成ツールで作成されたエントリ。
- **Deleted** — 一括削除ツールで削除されたエントリ。
- **Bench** — アップロードされたベンチセッション。

失敗したアップロードには **↺ 再試行** ボタンが表示され、該当ファイルのヒント付きでアップロードページに戻れます。

Word または PDF のレビューパネルから **CSV エクスポート** も可能です（「全エントリ」または「アップロード済みのみ」を選択）。

---

## マルチサーバープロファイル

複数の elabFTW サーバーを使い分ける場合は、ナビゲーションバーの **Profiles** を使います。

1. サーバーに接続して API キーを入力します。
2. ナビバーの **Profiles** → 名前を入力 → **Save**。
3. ワンクリックでプロファイルを切り替えられます — API キーの再入力は不要です。

API キーはブラウザのローカルストレージにのみ保存され、どのサーバーにも送信されません。

---

## 実験の管理

**Create / Delete** タブでは以下が行えます。

- **作成** — 空の実験エントリを手動で作成（ベンチセッション前の準備などに）。
- **削除** — 検索バーで 1 件削除。
- **一括削除** — 実験を検索してチェックボックスで複数選択し、一括削除。

---

## テンプレート選択

アップロードセッションごとに異なる elabFTW テンプレートを使用できます。レビューパネルのヘッダーにある **Template** ドロップダウンで切り替えます。テンプレート横の **👁** ボタンで内容を確認してから選択できます。

---

## ユーザー情報

API キーを入力すると、ナビゲーションバーにあなたの名前が表示されます。どの elabFTW アカウントがアクティブか、またキーに正しいチームメンバーシップがあるかを確認できます。

---

## ダークモード

ナビバー右上の **☾** ボタンでダークモードを切り替えます。設定は保存されます。

---

## 高度な機能 — AI タグ候補

Anthropic API キーがある場合、各実験エントリのタグ候補を自動生成できます。セットアップウィザードまたは **Settings** でキーを入力してください。タグ候補はレビューパネルにインラインで表示され、採用または却下できます。

---

## トラブルシューティング

### 「elabFTW に接続できません」
- サーバー URL が正しいか確認してください（`https://` を含む）。
- API キーが期限切れになっていないか確認してください。
- VPN を使用している場合は接続されているか確認してください。

### Linux でアプリが白い画面のまま
- `.deb` パッケージの場合は `--no-sandbox` オプションを試してください。
- ランディングページの **Logs** ボタンでバックエンドのエラーメッセージを確認してください。
