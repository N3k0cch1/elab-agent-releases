# elab-agent — releases

Download the latest installer for your platform from the [Releases](../../releases/latest) page.

| Platform | File | Notes |
|----------|------|-------|
| Windows | `*-setup.exe` | Silent installer — double-click, no wizard |
| Windows | `*-portable.exe` | Portable, no install needed |
| macOS Apple Silicon | `*-arm64.pkg` | 3-click installer |
| macOS Intel | `*-x64.pkg` | 3-click installer |
| Linux | `*.AppImage` | Make executable, double-click |
| Linux | `*.deb` | `sudo dpkg -i *.deb` |
